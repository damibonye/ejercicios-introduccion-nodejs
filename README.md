## Ejercicios

| Carpeta | Archivo | Descripción |
|---|---|---|
| `ejercicio1-informe-sistema` | `sistema.js` | Informe del sistema (os + picocolors) |
| `ejercicio2-explorador-carpetas` | `listar.js` | Explorador de carpetas (fs + picocolors) |
| `ejercicio3-informe-archivo` | `informe.js` | Informe a archivo con historial (os + fs + picocolors) |

## Cómo ejecutar

Entra en la carpeta del ejercicio, instala las dependencias y ejecuta el archivo:

```bash
cd ejercicio1-informe-sistema
npm install
node sistema.js
```
